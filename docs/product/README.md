# Product

What we're building and why. Read this if you're trying to understand the app's purpose, scope, or domain rules — no engineering knowledge required.

## Files

- **[`overview.md`](overview.md)** — What this app is, who uses it, and what's out of scope.
- **[`user-stories.md`](user-stories.md)** — Original requirements as captured at project start, plus refinements added during design.
- **[`rules.md`](rules.md)** — Tournament rules, scoring system, brackets, state machines, and edge cases for tiny divisions.

## When to update files here

- Scope changes (added/removed user story) → `user-stories.md`
- Tournament rule clarification or change → `rules.md`
- Out-of-scope item changes → `overview.md`

If a change here cascades into engineering or infra changes, update those docs too. See [`../README.md`](../README.md).
