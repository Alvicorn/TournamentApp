# Overview

A web app for monitoring a live martial arts tournament. Three user groups with strictly tiered privileges:

- **Admin** — highest privilege. Configures the tournament, manages judges/participants/divisions, edits results, broadcasts info.
- **Judge** — runs individual matches. Logs in via a code, claims a match, scores it, submits.
- **Public** — view-only. Watches the dashboard, subscribes to competitors for notifications.

## MVP philosophy

KISS. Single active tournament at a time. Single judge per match. Generic +/- scoring. No bells and whistles beyond what's needed for a smooth tournament day.

## User roles & authentication

| Role | Auth | Identity |
|---|---|---|
| **Admin** | Email + password via Supabase Auth | Allow-listed email |
| **Judge** | 8-character alphanumeric code with checksum digit, tournament-scoped, no expiry | Generated by admin |
| **Public** | None | Anonymous device UUID stored in `localStorage` |

See [`backend.md`](../engineering/backend.md) for code generation details.

## Visibility rules — match statistics

Each match tracks: points for/against per round, final score, win/loss, opponent.

- **Admin & judges**: see everything.
- **Public**: see competitor, opponent, final score, who won, in how many rounds.
